## [2.0.0] - 2026-10-25

### Added

- The `quiet-ui` skill, with a one-question test for interface text.
- 11 anti-patterns in `references/patterns.md`.
- Placement rules for inline text, info icons, and the help page.
- 9 before/after examples.
- A validator and tests, run in CI.

### Changed

- Renamed from `ui-discretion`.
- Restructured as a directory skill with progressive disclosure.
